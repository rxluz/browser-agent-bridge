# Support

Use GitHub Issues for reproducible bugs and feature proposals. Include:

- Browser and operating-system version.
- Extension version.
- Bridge and MCP server version.
- Sanitized command input and error output.

Do **not** include tokens, cookies, SSO URLs, internal hostnames, private screenshots, or page contents that are not safe to publish.

For security concerns, use the process in [SECURITY.md](SECURITY.md).
