# Code of Conduct

We want Browser Agent Bridge to be a constructive, professional project.

Be respectful, assume good intent, give feedback about the work rather than the person, and protect other people's privacy. Harassment, discrimination, threats, doxxing, and sharing credentials or private browser data are not acceptable.

If you experience or observe conduct that violates this standard, report it privately using the process in [SUPPORT.md](SUPPORT.md). Reports will be handled discreetly and fairly.
